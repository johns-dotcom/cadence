Design-token deltas covered by RC-1..RC-6 in `_audit/01-design-system.md`; not re-reported per element.

## 1. Files compared (purpose & pairing)

OLD's page is a bank-reconciliation instrument: every money figure is either **Settled** (bank-basis, from `buildPnl.by_artist`) or **Committed/Invoiced** (invoice-side, bank-evidence-guarded), and the page discloses everything it excludes. NEW rebuilt the *collaboration* shell (meta, flags, comments, chat, socials, review feed, export) on a **single-layer, date-unbounded, regex-scoped invoice sum**. The 2026-08-27 plan deferred the ad pool ([INT]); the two-layer model, the queue view and the unattributed flow were NOT deferred — their absence is the headline defect set.

## 2. Route & permissions

- OLD: `/artist-campaigns`, `/artist-campaigns/:artist`, `/artist-campaigns/:artist/:song`, plus `?view=queue` rendered inside the index route so it inherits the page permission (ArtistCampaignsQueue.jsx:10-16, ArtistCampaigns.jsx:2303). Server gate: `requirePagePermission('/artist-campaigns')` — admins pass, non-admin Users pass with a page grant (boom routes :16-19).
- NEW: same three client routes behind `AdminRoute` (cadence App.jsx:175-177); nav Approver+ (Layout.jsx:260); server `authMiddleware, withTenant, requireApprover` (routes :16). Tenancy = **intentional divergence**. The Approver+ floor (vs OLD's grantable page permission for plain Users) is a permission-model divergence — flagged as [INT] under cadence's finance-gating convention, but note plain Users can no longer be granted this page.
- NEW has **no `?view=queue`** — see DEF-ACAM-02.

## 5. Behavior/interactions diff

- **The two-layer contract (DEF-ACAM-01).** OLD's page exists because "this page used to read INVOICES and call the total 'actual'" (boom routes :93-97 tells the Jerri story: $274,289 vs $157,831). Settled comes from `buildPnl.by_artist` so it ties to the P&L by construction; Committed is bank-evidence-guarded and date-unbounded; the two are addable because `bank_evidence IS NOT NULL` is the double-count guard (:110-112). NEW's `actual_total` is exactly the pre-fix construct: an invoice-side sum labeled as actuals — and cadence HAS the ingredients (`lib/bankEvidence`, `reports.js buildPnl` exports `by_artist`) unused by this route.
- **Queue (DEF-ACAM-02).** OLD's queue is the backlog surface (284 campaigns, 23 finished when built — routes :400-404), deliberately a `?view=` of the same route for permission inheritance (Queue.jsx:10-16), with the PROBLEMS array as the single definition for chips, filters and counts (:41-49) and money labeled `invoiced`/`unsettled`, never "settled" (:18-21). NEW has `song_campaign_status.finished` per song but no cross-artist worklist of unfinished campaigns.
- **Attribute-unattributed (DEF-ACAM-03).** OLD: the index states the gap (`meta.unattributed`), the modal pulls the Reports artist-drill for each category (`kind='artist', key=''`), nets the reimbursements block so the list ties to the figure it was opened from (client :418-427), writes `/reports/set-artist` on **part ids** so a split slice never drags its sibling (:507-512), and turns vendor selections into label-level **equality rules** (:442-463). NEW: unattributed rows are structurally invisible (`artist <> ''` in VISIBLE) and no attribute affordance exists on this surface. cadence's Reports page has its own drill/set-artist — but the campaigns page neither links it nor discloses the gap.
- **Committed money silently narrower (DEF-ACAM-06/07).** Excluding `pending` reverses OLD's explicit choice to count vendor-submitted invoices as committed spend; excluding nothing by `entry_source` reverses OLD's explicit choice to exclude statement-born families. Both change totals without any disclosure line (which DEF-ACAM-04 removed).
- **rename-song (DEF-ACAM-08).** OLD's three-cascade transaction exists because the ledger, Release Tracker and finished-flags must move together (routes :1556-1568). NEW moves only expenses, row-by-row outside a transaction, and no UI calls it — the endpoint is dead code that would orphan `song_campaign_status` if wired.
- **Orphaned endpoints.** NEW server ships `/review-assign` (:155), `/link` (:274), `/restore` (:244), `/:artist/rename-song` (:375) with zero client callers (grep across cadence client) — DEF-ACAM-11/12/14/08.
- **Review inbox math (DEF-ACAM-11).** `feedCount = flaggedRows + flaggedSongs + flaggedArtists` (index :44) but only the first two render (:61-71) — the badge can say 5 while the tray shows 3. `openThreads` is fetched and never used.
- **Bulk mutations** loop `await` per id (detail :60) — n round-trips, no partial-failure report; OLD acts per-row so no equivalent. Minor.
- **Dismiss has no undo (DEF-ACAM-14).** OLD pairs dismiss with an undo toast + a dismissed tray (`?include_dismissed`, dismissed_count, per-row Restore, routes :1243-1245, :1349-1363). NEW's detail dismiss() drops the row on next load with no path back from this page (server `/restore` exists, uncalled).
- **Chat**: NEW polls 8s full-refresh, localStorage seen-marker + server read post; OLD does `?after` incremental + server watermark + mention deep-links (room_title/path). Capability parity via cadence's `recordMentions` bell — [INT], with the polling-efficiency note only.

## 6. Visual/design diff

RC-1..RC-6 apply page-wide. Beyond those:

- OLD index cards are `md:grid-cols-2` wide two-layer ledger cards with a right money rail; NEW `lg:grid-cols-3` compact single-number cards — the page reads as a gallery, not a reconciliation sheet. Folded into DEF-ACAM-01/10.
- Priority: OLD three discrete H/M/L buttons expressly because native `<select>`s had cross-browser/touch failures on cards (boom client :2626-2630); NEW went back to a native `<select>` styled as a chip (index :89-92) — reintroduces the exact quirk OLD documents. Part of DEF-ACAM-10.
- NEW export header hardcodes Boom red `FFDC2626` (cadence routes :415) in a multi-tenant product whose accent is per-label (RC-2) — visual parity with OLD achieved by copying the *brand constant*, DEF-ACAM-21 (P5).
- OLD queue/index metadata is dense bracket-type (`text-[10px]`/`text-[10.5px]` per RC-3); NEW uses the same sizes on chips but drops the sub-labels (bank-line tooltips, "since {date}") entirely rather than restyling them.
- Row washes (flag amber > not-campaign gray > finished emerald > provenance indigo/purple, detail :21-28) are a reasonable NEW condensation of OLD's row treatments — no defect.
